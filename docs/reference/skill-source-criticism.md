# source-criticism

| Field | Value |
|---|---|
| Type | Skill |
| File | [`skills/source-criticism/SKILL.md`](../../skills/source-criticism/SKILL.md) |
| Loaded when | before relying on any historical source - judging who made it, when, where, for whom and why; how it reached us (provenance, copies, editions, translations); whether its author could know what it says; what its genre, audience and the power behind it bias; corroborating it with independent sources; reading against the grain for the people a record leaves out; and grading what it can support. |
| Referenced by | [research-brief](workflow-research-brief.md), [reference-set](workflow-reference-set.md), [fact-check](workflow-fact-check.md) |

## Inputs

A source and the question asked of it.

## Outputs

A judgement of the source (maker, date, purpose, access, edition, bias), corroboration, and a grade for each claim it supports.

## At a glance

| Step | Does |
|---|---|
| Ask of every source | Who, when, where, for whom, why, how they could know, what kind of thing, how it reached us, what it leaves out |
| Provenance and editions | Holder and identifier; original or facsimile, then scholarly edition, then translation |
| Bias of the record | Who the record served; reading against the grain; the community's own sources |
| Corroboration | An independent second source; copies count as one; conflicts recorded |
| Grades | Attested, inferred, contested, unknown |
| Fakes and errors | Authentication, excavation context, catalogue records |

## Quality bar

- Every source used has maker, date, purpose, access and holding noted.
- Every claim the product builds on is corroborated or marked as resting on one source.
- Conflicts are recorded, not hidden.

## Documentation owed

Source notes in the brief; a reference entry for a recurring source with known problems. Written in the same change as the work, one Diataxis kind per page.
