# historical-research

| Field | Value |
|---|---|
| Type | Skill |
| File | [`skills/historical-research/SKILL.md`](../../skills/historical-research/SKILL.md) |
| Loaded when | a product needs something about the past found out - turning a team's need into research questions tied to the decisions they feed, choosing the depth, planning where answers can be found (primary sources, archives and digital editions, scholarship, reference works, museum collections), searching in the right languages, keeping research notes and a search log, knowing when to stop, and handing on an answer with its confidence. |
| Referenced by | [research-brief](workflow-research-brief.md), [reference-set](workflow-reference-set.md), [fact-check](workflow-fact-check.md) |

## Inputs

The team's need: who asks, the decision it feeds, and the period, place and people.

## Outputs

Research questions with the depth chosen, a search log, notes, and an answer with its confidence and citations.

## At a glance

| Step | Does |
|---|---|
| Start from the decision | Who needs it, for what decision, the research questions, scope and depth |
| Plan | Where each answer lives: primary sources, collections, scholarship, reference works; which languages |
| Search and log | Period and modern terms; citations backwards and forwards; empty results logged |
| Read and judge | Every source judged; key claims corroborated |
| Stop | Answered, saturated or exhausted, and say which |
| Hand on | Answer and confidence first, then meaning, evidence and open questions |

## Quality bar

- Each question names the decision it feeds and the depth chosen.
- The search log shows empty results too.
- Nothing rests only on an encyclopedia, a popular site or generated text.

## Documentation owed

The answer or brief as a reference page with its search log and bibliography; an explanation page for a debate the team needs to understand. Written in the same change as the work, one Diataxis kind per page.
