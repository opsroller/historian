# citation-and-evidence

| Field | Value |
|---|---|
| Type | Skill |
| File | [`skills/citation-and-evidence/SKILL.md`](../../skills/citation-and-evidence/SKILL.md) |
| Loaded when | whenever research is written down or handed on - citing every claim so a reader can follow it to the page, folio, plate or object (Chicago notes and bibliography unless the project names another style), citing digital editions and museum records, keeping a claim ledger with confidence grades, separating quotation from paraphrase, crediting intellectual debts, and never fabricating or altering evidence. |
| Referenced by | [research-brief](workflow-research-brief.md), [reference-set](workflow-reference-set.md), [fact-check](workflow-fact-check.md) |

## Inputs

Research notes and the project's citation style.

## Outputs

Notes and bibliography that can be followed to an exact place, and a claim ledger with grades.

## At a glance

| Step | Does |
|---|---|
| Cite so it can be followed | Edition read, exact page, folio, plate or object; archive shelf marks; record identifiers, stable URLs and consultation dates |
| Claim ledger | Claim, grade, sources, notes for every claim the product builds on |
| Quotation and paraphrase | Exact quotes checked against the source; own translations marked |
| Never | Invent, alter, take credit, or cite generated text |
| Generated text | Only to suggest where to look |

## Quality bar

- Every claim can be followed to an exact place in a named edition or record.
- Every quotation was checked against its source.
- Bibliography and notes agree.

## Documentation owed

Notes and bibliography with every research page; the claim ledger in each brief, reference set and fact check. Written in the same change as the work, one Diataxis kind per page.
