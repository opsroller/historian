# visual-and-material-reference

| Field | Value |
|---|---|
| Type | Skill |
| File | [`skills/visual-and-material-reference/SKILL.md`](../../skills/visual-and-material-reference/SKILL.md) |
| Loaded when | artists, designers or audio need to know what something in the past looked, felt or sounded like - building a sourced reference set of architecture, objects, dress and adornment, materials and techniques, colour and pigment, iconography, writing and ornament, landscape and plants; recording for each item its holder, identifier, date, place, rights status and what it does and does not show; separating surviving evidence from reconstruction; and briefing the artists on how to use it without copying. |
| Referenced by | [reference-set](workflow-reference-set.md), [fact-check](workflow-fact-check.md) |

## Inputs

A subject, the people who will use the set, and the categories they need.

## Outputs

A reference set with an item table per category and an artist brief (essentials, do and avoid, gaps, no copying).

## At a glance

| Step | Does |
|---|---|
| Categories | Architecture, objects, dress, materials, colour, iconography, landscape, sound |
| Record every item | Holder and identifier, date, place, kind of evidence, shows, limits, rights, sensitivity |
| Evidence versus reconstruction | Reconstructions labelled; survival bias; elite, ritual and everyday; regional and period differences |
| Brief the artists | Essentials, do and avoid tied to items; reference informs original work, never copied |

## Quality bar

- Every item has holder, identifier, date, place, kind of evidence and rights status.
- Every reconstruction is labelled as one.
- No sensitive item is used without the decision recorded.

## Documentation owed

The reference set as a reference page linked from the art-direction or design docs; an explanation page for an interpretive choice. Written in the same change as the work, one Diataxis kind per page.
